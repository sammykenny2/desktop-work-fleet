# 使用說明

[English](user-guide.md)

更新：2026-10-17。

1.0 Work Fleet 在 Windows、macOS、Linux、手機與瀏覽器預覽中的操作方式。建置、執行與封裝方式，以及 0.1.0 驗證版的用法，
見 [Setup](setup-guide.md)（英文）。目前狀態見 [PROGRESS](../PROGRESS.md)。

以下引用的按鈕與選項名稱以繁體中文介面為準；英文版引用英文介面。切換方式見 [設定](#設定)。

## 開始使用

- 沒有 Google 帳號也能離線記錄：App 從「本機便箋」開始，內容只存在這台裝置。
  之後要跨裝置同步再登入 Google（見 [Google 登入與同步](#google-登入與同步)）。
- 側欄的「＋ 記下想法」開啟新便箋的 editor。設定在側欄左下角的齒輪，也可以按 Ctrl+,（macOS 為 Command+,）。
- 窄螢幕與手機把側欄收進左上角按鈕開啟的抽屜，新增改用右下角的「＋」按鈕。
- 同 profile 不允許第二個獨立視窗寫入；保存中或失敗時離頁有提示。
- 電腦版另有桌面便箋、系統匣（macOS 為選單列）與全域快捷鍵；見 [桌面便箋與層級](#桌面便箋與層級) 與
  [系統匣與選單列](#系統匣與選單列)。

## 便箋與編輯器

- 「＋ 記下想法」開啟 editor，支援 Markdown／checklist（「＋ Checklist」新增步驟，「預覽 / checklist」檢視結果）；
  「＋ 附件」可附加每檔至多 25 MiB 的檔案。
- 「標題（選填）」可留空：有填時紙張頂部顯示標題，沒填時顯示內文第一行；內文都從第一行開始顯示。
- 附件僅下載，不直接執行 HTML／SVG。
- 「保存便箋」完成後會移除對應草稿；「保留草稿」則留下草稿，之後可從側欄的「未完成草稿」繼續。
- Ctrl／Command＋Enter 保存；Esc 保留草稿並結束編輯；空白或未修改的內容不保留草稿。完整編輯可管理附件及預覽。
- 桌面紙面可就地編輯，Ctrl+Enter 保存、Esc 保留草稿退出編輯（空白或未修改不保留）；
  「完整編輯」回到主畫面的 editor 處理附件等內容。
- 新便箋預設 240×240 正方形，群組區域較矮時縮成放得下的正方形（最小 160×160）；
  已在桌面上的便箋維持原尺寸，「重置桌面佈局」後才套用。
- 桌面上能操作的便箋內文可以捲動；桌布層與主畫面便箋牆的便箋不能捲動，內文放不下時以「…」收尾，看全文請開啟編輯。
- 有附件時，紙張底部有一排縮圖由左往右排，排不下的不顯示；雙擊縮圖開啟附件。

### 版本與衝突

- 側欄的「版本與衝突」分為「需要處理」與「版本歷史」兩頁，可比較分支、採用版本（「採用此版本」）、下載其附件、
  恢復較早內容（「恢復為目前版本」），並處理群組合併循環。
- 恢復會建立新版本，保留後來的內容；未完成草稿仍可取回。多分支尚未處理時一般保存會保留草稿並提示。
- 群組沒有接收目的或超過九組時，資料保留並提供整理說明。未完成轉組可重試（「以目前版本重試轉組」）
  或取消（「取消這次轉組意圖」）。

## 群組

- 側欄「我的群組」旁的「＋」開啟「新增群組」。
- 群組旁的「⋯」開啟「群組設定」，可重新命名，或用「合併／移除群組」併入另一組：先選接收群組並預覽所有卡片及草稿，
  再按「確認合併並移除原群組」。確認後內容與桌面位置保留，來源群組移除；復原無法重建已合併的群組。
- 要把便箋移到另一組，在調整模式中拖過去（見 [調整模式與排列](#調整模式與排列)），或在便箋「⋯」詳情的「移至群組」選擇。
- 整理便箋時，每個群組會排進自己的區域。「設定 → 桌面」的「群組區域」可設定「列」與「欄」，並在下方為每個區域選擇群組；
  選擇已在其他區域的群組會交換兩個區域。區域由左到右、由上到下編號。
- 側欄依區域順序列出群組，順序由每台裝置各自保存。上下拖曳群組即可調整順序；手機上拖曳列左側的點狀握把，
  鍵盤則在群組上按 Alt+↑ 或 Alt+↓。調整順序會讓群組在各自的區域之間換位，區域鍵也跟著改變；
  已在桌面上的便箋要等整理時才會移動。群組超過九個時（同步離線變更後）要先合併才能調整順序。
- 每個群組在這台裝置上有一種便箋顏色（九選一），在群組的「⋯」→「群組設定」→「這台裝置上的顏色」選擇；
  有小圓點的顏色已被其他群組使用，選它會讓兩組互換顏色。新群組會取用沒有群組使用的顏色，合併後原群組的顏色會釋出。
  顏色不同步，每台裝置各自保存，調整群組順序也不會改變顏色。
- 「設定 → 桌面」的「我的群組」讓這台裝置上某一組的便箋加上強調色邊。
- 每個群組在一個桌面層級上；見 [桌面便箋與層級](#桌面便箋與層級)。

## 便箋牆與清單

- 電腦版的主畫面不鏡像桌面版面；拖拉直接在桌面上進行。
- 篩選列右側切換「便箋」（正方形紙張網格）或「清單」，選擇記在這台裝置；點一張便箋開啟編輯。第三個檢視依平台不同：
  - 電腦版：「版面地圖」，目前只是空白預留畫面。
  - 瀏覽器預覽：「桌面」，在頁面內的畫布上依群組區域顯示待處理的便箋，可在這裡排列（見 [瀏覽器預覽](#瀏覽器預覽)）。
  - 手機沒有第三個檢視。
- 篩選「待處理」「已完成」「封存」「刪除區」分別列出各狀態的便箋，並可還原；搜尋標題與全文。
- 已完成的便箋仍留在桌面並標示為已完成，除非這台電腦隱藏它們（見下方「顯示已完成的便箋」）；封存或刪除會讓便箋離開所有裝置的桌面。
- 便箋「⋯」詳情的「移至刪除區」不會先詢問。底部狀態列會提供「復原」，直到下一則訊息出現；便箋會留在刪除區，直到你在那裡還原。

## 桌面便箋與層級

桌面便箋只在電腦版（Windows、macOS、Linux）提供。

- 每個群組在一個層級上，由後到前為桌布層、桌面層、最上層。在這台電腦建立的群組（包括第一個群組），
  以及登入或與 Google 同步時第一次帶到這台電腦的群組，都放在最後面：桌布層；桌面沒有桌布層時放桌面層。
  這台電腦原本就有的群組維持原本的層級，直到「重置桌面佈局」把每個群組都移到最後面。
  按該組的區域鍵（預設 Ctrl+Shift+1–9，見 [快捷鍵](#快捷鍵)）依序切換。
- 層級屬於群組、每台電腦各自保存。電腦版也可以在群組旁的「⋯」→「群組設定」選「桌面上的層級」；
  手機與瀏覽器預覽沒有這個選項。便箋的「⋯」詳情只保留「在桌面顯示」。
- 桌面層與最上層的便箋在「鎖定中」也可以選取文字、點連結，不會穿透滑鼠；桌布層固定穿透。
- 「設定 → 桌面」的「鎖定時也顯示便箋」需開啟，才會在鎖定狀態常駐；關閉後，便箋只在調整時出現在桌面上。
- 「設定 → 桌面」的「顯示已完成的便箋」預設開啟。關閉後，已完成的便箋會離開這台電腦的桌面，調整時也不出現；重新開啟或改回待處理，便箋回到原來的位置。每台電腦各自設定，「重置桌面佈局」會把它重新開啟。
- Windows Explorer 環境的桌布層附著到圖示下方。macOS 同一操作入口使用 AppKit 三層；Linux layer-shell 使用三個原生 band。
- pcmanfm 桌面將桌布和圖示畫在同一 surface，便箋無法放在圖示下方，所以不提供桌布層；它與 X11 的桌布偏好都回退桌面層，
  「群組設定」會標出實際顯示的層級。上述範圍、穿透／重畫及原生驗證見 [ADR-031](decisions/031-macos-and-linux-wallpaper-scenes.md)。
- 宿主不可用時會提示暫以桌面層呈現，原偏好保留；分層決策見 [ADR-030](decisions/030-windows-explorer-wallpaper-layer.md)。
- 調整管理視窗大小不搬動桌面卡片。啟動採當時顯示器拓撲與工作區；熱插拔恢復仍待整合。
- 各平台細節（GNOME Wayland、Raspberry Pi OS、pcmanfm）見 [Linux](#linux)。

## 調整模式與排列

- 便箋平時處於「鎖定中」，無法改文；按「調整此組」或「調整全部」進入調整模式後單擊選卡、雙擊就地編輯，按「完成」回到鎖定。
- 桌面版的調整模式以半透明遮罩覆蓋螢幕，上方有「調整位置」與「堆疊」「攤開」「復原」「完成」；
  進入時主視窗有焦點才會先最小化，結束後恢復（[ADR-042](decisions/042-adjust-overlay-on-every-desktop-host.md)）。
- 主畫面的「調整此組」與「調整全部」讓對應卡片暫時移到最上層，按「完成」後回到該組的層級。
- 拖曳只移動位置；放在另一組接收標籤或按住 Shift 放到另一組區域才轉組。
- 「堆疊」／「攤開」（排列）先預覽，按「套用排列」才執行；調整大小須每次勾選「允許這次調整卡片大小」；
  「復原」依序還原 geometry／轉組。

## 快捷鍵

- 「設定 → 快捷鍵」列出「快速記錄」「顯示或隱藏桌面便箋」，以及「便箋層級與位置」下的「所有群組」與區域 1–9；
  每個區域列以該區域目前的群組命名（沒有群組時為「空白」）。
- 可用 Ctrl／Alt／Meta 搭配字母、數字或 F1–F24，可加 Shift；多組以逗號分隔，留空取消。
- 預設快速記錄 Ctrl+Shift+N，顯示或隱藏桌面便箋 Ctrl+Shift+D，所有群組 Ctrl+Shift+0，區域 1–9 為 Ctrl+Shift+1–9。
- 桌面版的區域鍵每按一次，整組便箋換到下一階：桌布層 → 桌面層 → 最上層 → 調整位置，再按回到桌布層。
  不支援桌布層的桌面跳過桌布層。
- 每次切換，該組區域中央會在最上層短暫顯示群組名稱、目前層級與各階的圓點，約 1.5 秒後淡出，不會擋住滑鼠。
- Ctrl+Shift+0 讓所有群組進入調整位置，再按一次各自回到原本的層級。
- 關閉「鎖定時也顯示便箋」時，或在瀏覽器預覽中，區域鍵只切換該組的調整位置，不換層級。
- 區域由左到右、由上到下編號；數字鍵跟著區域，作用於當下在該區域的群組，空白區域的鍵不向系統註冊。
- 舊版綁在群組上的鍵，開啟時改成該群組所在的區域，沒有鍵的區域補上預設數字。
- 瀏覽器若保留該組合可在設定改鍵；預覽只在目前視窗生效，不宣稱已向 OS 註冊全域鍵。
- Windows 全域快捷鍵依設定啟用；設定內顯示每鍵是否已註冊、「已被其他程式使用」或「系統保留」，
  可按「重新註冊快捷鍵」重試或改鍵。Ctrl+Alt 加字母／數字不作全域註冊，以保留 AltGr 產字；該列會提示「請改用 Ctrl+Shift 組合」，也可改用 function-key 組合。
  App 取得焦點時釋放全域註冊，由目前視窗處理本地按鍵；組字與對話框優先。

## 設定

設定在側欄左下角的齒輪，也可以按 Ctrl+,（macOS 為 Command+,）。變更立即生效，但不會重排既有便箋。

- 「一般 → 顯示語言」：「自動偵測」「英文」「繁體中文」。各選項以目前介面的語言命名。
  - 「自動偵測」（預設）會跟隨這台裝置的語言：依序取系統偏好語言中第一個英文或繁體中文（含不帶地區的中文、香港與澳門）。
    簡體中文與其他語言會略過；都不符合時使用英文。
  - 選擇後視窗立即切換、不重新載入；桌面便箋、系統匣、macOS 選單列與應用程式選單，以及 App 自己顯示的對話框也改用同一語言。
    已顯示的狀態列文字要到下次更新才換語言。
  - 手機也有同一設定；iOS 的分享延伸功能畫面也會跟著切換。
  - 這個選擇屬於這台裝置，不進入備份或 Google 資料。
- 「帳號與同步」：見 [Google 登入與同步](#google-登入與同步)。
- 「資料與備份」：見 [備份與還原](#備份與還原)。
- 「桌面」（電腦版與瀏覽器預覽；手機沒有「桌面」與「快捷鍵」頁）：「鎖定時也顯示便箋」「顯示已完成的便箋」「我的群組」「群組區域」與「重置桌面佈局」。
  電腦版另有「啟動行為」「版本與更新」與「重置主視窗」；GNOME Wayland 另有「以 XWayland 顯示桌面便箋」（見 [Linux](#linux)）。
- 「快捷鍵」：見 [快捷鍵](#快捷鍵)。

### 啟動與主畫面

電腦版「設定 → 桌面」的「啟動行為」有以下開關，各自顯示系統實際的狀態：

- 「登入電腦時啟動 Work Fleet」。若已在系統（Windows 的「啟動應用程式」、macOS 系統設定的「登入項目」）關閉，
  這一列會說明，請到那裡重新開啟。
- 「關閉主畫面時保留在系統匣」（macOS 為「關閉主畫面時保留在選單列」）。關閉時，關閉主畫面會保存並結束 Work Fleet。
- 「登入啟動後開啟主畫面」。關閉時，登入後只在背景顯示桌面便箋；自己開啟 Work Fleet 時一律顯示主畫面。

「重置主視窗」下的「重置主視窗大小與位置」讓主視窗回到預設大小，並置中於主要螢幕。桌面便箋不受影響。

### 重置桌面佈局

「設定 → 桌面」最下方的「重置桌面佈局…」經確認（「重置」）後，只把這台電腦的便箋放回各群組區域、恢復預設大小與顯示方式，
並把每個群組移到最後面的層級（桌布層；桌面沒有桌布層時為桌面層），不動內容、群組名稱與內容、快捷鍵。草稿仍留本機；還原備份時是否套用其版面另行選擇（「一併還原桌面位置」），既有新資料匯入不搬動舊卡。

## Google 登入與同步

- 原生 App 在「設定 → 帳號與同步」的「Google 帳號」列按「登入」；點側欄左下角的帳號區直接開啟該頁。
  瀏覽器開發預覽沒有 Google 登入或同步，只有本機資料。
- 登入不會自動傳送既有本機便箋或瀏覽器預覽資料；搬移方式及其他帳號操作見 [Google 設定](google-setup.md)（英文）。
- 登入 Google 後若要全部覆蓋，使用「清空 Google 後，從備份還原」；見 [備份與還原](#備份與還原) 與 [Google 設定](google-setup.md)。
- Google 工作空間的「重設所有資料」會連 Drive 的資料一起清，所有使用這個帳號的裝置都受影響。
- Linux 的 Google 權杖需要已解鎖的金鑰圈；見 [Linux](#linux)。

## 備份與還原

### 匯出與匯入

- 「資料與備份」的「匯出備份」可存成明文 ZIP，勾選「用密碼加密」則加密。還原時在「從備份還原」選擇檔案並按「檢查檔案」，
  驗證並預覽後按「確認還原」；「還原方式」有「加入成新的便箋」「與目前的便箋合併」「取代目前的便箋」。
- 加密輸出至少 12 個字元，手動匯出的密碼不保存且無法找回；還原使用原密碼。
- 「加入成新的便箋」另建資料，「與目前的便箋合併」依原身分保留分支；「取代目前的便箋」保留歷史並把額外便箋移至刪除區。
- 「取代目前的便箋」需先成功保存目前資料的安全備份（「先備份目前資料」）；只支援下載而無法確認保存的瀏覽器會停用此步驟。
- 原生 App 的手動匯出使用原生資料夾選擇器，每次建立 `work-fleet-backup-UUID.zip` 新檔並讀回校驗。
  讀取可攜備份仍可使用一般檔案選擇器。
- 本機與 Google 備份格式相同；Google 匯出先同步，失敗須明確選擇「只備份這台已知資料」。
- 下載 Google ZIP、切換本機後還原即可離線使用；詳細雙向流程見 [Google 設定](google-setup.md)。
- 目前測試階段便箋與備份的資料格式維持 V1，更新欄位不會啟動 schema 升級或建立額外副本。
  資料版本政策見 [SPEC-007](specs/007-schema-evolution-and-migrations.md)；平常仍可使用既有 ZIP 備份。

### 清空後從備份還原

- 本機工作空間另有還原方式「清空本機後，從備份還原」：按「檢查檔案」檢查 ZIP、核對清除數量、
  勾選「我了解目前本機內容會永久被備份取代」，再按「確認還原」。
- 不需先重設或強制備份舊內容；同交易替換便箋、歷史、草稿、附件與版面，失敗保留原資料。
- 舊內容不留在刪除區，自動備份設定與其他工作空間保留；仍可選「先備份目前資料」。
- Google 工作空間使用「清空 Google 後，從備份還原」全部覆蓋；見 [Google 設定](google-setup.md)。

### 自動備份

- 自動備份預設關閉，在「資料與備份」的「自動備份」以「選擇資料夾」設定「位置」，填入密碼與「保留份數」後按「開啟自動備份」。
- 預設保留七份，有變更且距成功滿 24 小時才備份，開啟／恢復時補跑；「立即備份」馬上執行一次。
- Windows 的密碼由 DPAPI 保存在目前 Windows 帳號，renderer 只取得金鑰 ID；換裝置還原仍需自行保管原密碼。
- 「停用」或換位置會保留舊檔；未完成、被改過或替換的檔案會保留並顯示問題。
- Windows 的保存目前只支援本機 NTFS 資料夾，拒絕網路磁碟、FAT／exFAT、symlink／junction。
- 瀏覽器預覽的自動備份入口明示不支援並停用。上述是 Windows 原生操作；其他平台的目前狀態見 [PROGRESS](../PROGRESS.md)。

### 重設所有資料

- 「資料與備份」最下方的「重設所有資料…」刪除目前工作空間在這台裝置上的便箋、群組、草稿、附件、歷史、佈局、快捷鍵與自動備份設定，
  旁邊有「先匯出備份」；在「重設所有資料？」對話框需勾選「我了解刪除後無法復原」，才能按「永久刪除並重設」執行。
  已保存的備份 ZIP、分享收件匣中尚未接收的分享與其他工作空間不受影響。
- Google 工作空間會連 Drive 的資料一起清，所有使用這個帳號的裝置都受影響（見 [Google 設定](google-setup.md)）。

### 自行保存副本

- 沒有 Google 同步，清除瀏覽器資料會失去預覽資料；可先用「設定 → 資料與備份」保存 ZIP。
- 不要把原生 DB 當成跨機備份，Windows 的 DPAPI 需原 Windows 帳號金鑰。
- 預覽 IndexedDB 與 native 是不同 profile，不自動搬動既有資料。
- Windows 上 MSIX 更新與解除安裝保留哪些資料，見 [Windows](#windows)。

## 系統匣與選單列

- 「關閉主畫面時保留在系統匣」開啟時（預設；macOS 為「關閉主畫面時保留在選單列」），視窗 X 收起到系統匣（macOS 為選單列）。
  結束請用 Windows 系統匣的「保存並結束 Work Fleet」，或 Linux 系統匣與 macOS 選單列的「保存並結束」；
  開關關閉或系統匣不可用時，X 才保存並退出。
- 視窗 X 或 Windows 系統匣「收起主畫面」後，桌面及本機資料權威繼續執行；系統匣可重新開啟、快速記錄、操作或退出。
- Windows 系統匣選單有「開啟主畫面」「快速記錄」「調整所有便箋」「完成調整」「顯示／隱藏桌面便箋」「收起主畫面」、
  「檢查更新…」（支援 App 內更新時）與「保存並結束 Work Fleet」。
- Linux 系統匣與 macOS 選單列有「開啟 Work Fleet」「快速記錄」「調整所有群組」「顯示／隱藏桌面便箋」、
  「檢查更新…」（支援 App 內更新時）與「保存並結束」；macOS 應用程式選單另有「保存並結束 Work Fleet」。
- 系統匣與選單的文字跟隨「設定 → 一般 → 顯示語言」。
- 延遲後焦點若已改變，點一下浮動卡片即可繼續。
- 關閉主畫面時是否保留在系統匣，是「設定 → 桌面」的開關；見 [啟動與主畫面](#啟動與主畫面)。

## 更新

- 「設定 → 桌面 → 版本與更新」顯示版本、安裝形式與 App 內更新狀態；單一按鈕提供下一步：「檢查更新」「下載更新」或「重新啟動並安裝」。
  系統匣與選單列也有「檢查更新…」。
- Work Fleet 只在你要求時檢查更新，沒有自動或定期檢查。
- 「重新啟動並安裝」會先保存未保存的文字；Work Fleet 會關閉，安裝完成後重新開啟。備份或還原進行中時，請完成後再安裝。
- 只有能原地升級的安裝形式支援 App 內更新：Windows 安裝版（MSIX）、已簽章並公證的 macOS App（以 Sparkle 更新），
  以及從 DEB 安裝的 Linux（經 pkexec 安裝）。其他形式（例如 Windows ZIP）只顯示版本。

## 平台說明

### Windows

- 沒有 Google ID 也能離線記錄；內容、附件、草稿、版面與備份 journal 儲存於
  ZIP／Debug 的 `%LOCALAPPDATA%\WorkFleet\fleet.sqlite3`，或 MSIX 套件私有資料區的
  `LocalCache\Local\WorkFleet\fleet.sqlite3`，payload 使用目前 Windows 使用者的 DPAPI 保護。
- MSIX 更新保留資料；解除安裝清除套件內全部本機／Google 帳號資料、設定、憑證及 cache。
  重裝前先匯出 ZIP；匯出的檔案與 Google 雲端不受影響。
- 舊獨立目錄需以舊版／ZIP 匯出再於 MSIX 匯入，不自動搬移或刪除。
- 同一路徑只允許一個 App，另一個視窗會提示使用原視窗。
- 關閉先等草稿保存及自動備份收尾；還在對話框或 IME 輸入時先完成該操作。
  保存失敗保留視窗及草稿；重新開啟會讀取已提交內容。

### macOS

- 關閉按鈕讓 Work Fleet 留在選單列；選單列的「保存並結束」才保存並結束。
- 桌面便箋使用 AppKit 三層，操作入口與 Windows 相同。

### Linux

- 新工作空間與完成主金鑰遷移的離線便箋不需要 keyring。
  Google 權杖、保存的自動備份密碼及舊資料首次遷移需要 libsecret／已解鎖的持久 Secret Service；
  鎖住時只暫停相關功能，開機與背景同步不要求密碼（[ADR-048](decisions/048-linux-offline-workspace-and-system-secrets.md)）。
- 自動登入可能讓金鑰圈保持鎖定；按「立即同步」會開啟系統解鎖視窗，成功後接續同步，取消／逾時可再次重試。
- 桌面缺少全域快捷鍵或系統匣能力時，主畫面仍可記錄；各自需要的元件見 [Setup](setup-guide.md)。
- GNOME Wayland（例如 Ubuntu 22.04 預設）沒有 layer-shell，桌面便箋要經 XWayland；首次啟動會詢問
  「要改用 XWayland 顯示桌面便箋嗎？」（「改用 XWayland 重新啟動」或「維持目前方式」），
  之後可在「設定 → 桌面」的「以 XWayland 顯示桌面便箋」切換（[ADR-040](decisions/040-gnome-wayland-xwayland-choice.md)），
  也可直接以 `GDK_BACKEND=x11 work-fleet` 啟動。
  經 XWayland 時群組只常駐桌布層（[ADR-039](decisions/039-gnome-desktop-icons-and-x11-scene-size.md)）。
- Raspberry Pi OS（labwc）等 layer-shell 桌面的常駐層不受遮罩限制（預設 pcmanfm 桌面沒有桌布層），
  調整模式同樣以遮罩覆蓋整個螢幕並隱藏主視窗。

### 手機

- 手機沒有桌面便箋，因此沒有層級選項，設定中沒有「桌面」與「快捷鍵」頁，也沒有調整工具列。側欄與新增按鈕見 [開始使用](#開始使用)。

### 瀏覽器預覽

- 此預覽不是 OS 桌面浮層。「桌面」檢視在頁面內繪製便箋，群組在這裡沒有層級選項；實際分層／穿透／全域快捷鍵由原生 host 完成。
- 沒有 Google 同步；備份方式見 [自行保存副本](#自行保存副本)。
- 快捷鍵只在目前視窗生效，區域鍵只切換該組的調整位置。
- 不支援自動備份，入口停用。

# ADR-006: 一事一卡、群組操作與顯式 formation

## Status

Accepted（限使用者已確認的產品語意），2026-10-04。
授權其餘細節按最佳實踐規劃的部分，在 [SPEC-003](../specs/003-desktop-cards-groups-and-formation.md)
標為 D；尚未定案的功能範圍標為 Q。本 ADR 不接受具體框架／同步協定，也不代表已實作。

## Context

使用者需要隨手記錄靈感、看見 backlog 的跨裝置桌面便箋。
初期曾想每台開發機一張包含很多事情的 note，之後明確改為一張 post-it 一件事。
第一版仍不以完整專案管理為中心。群組可反映本機「屬於我」，但不是只能表示機器。
早期變動卡片高度的展示、按物理堆疊限制輪播、普通跨區拖放自動改組，都不符合後續澄清。

## Decision

1. Card/Note/Post-it 是同一種穩定身份的內容物件，一張代表一件事情。
   同一事情的說明或 checklist 步驟不因此被禁止；不自動拆解使用者本文。
2. Group 為邏輯集合，Region 為裝置的 formation 目標區；Group 不等於 Device。
3. 產品最多九組；grid 採列×欄，rows≤3、columns≤4、rows×columns≤9。
   2 列×4 欄及 3 列×3 欄可用，3 列×4 欄不可用。
4. 卡片可自由拖到別組區域；普通移位不改歸屬。
5. Formation 是單次位置整理授權，可作用於全部或單組；單組會召回被拖散的該組卡片。
6. Stack 露出各卡第一行摘要；spread 整齊攤開。卡片平常維持尺寸，不使用 accordion。
   Formation 必要時可在同意後改尺寸；未同意時可超出群組區域。
7. 輪播只暫時改疊序；目前組整組位於其他組上方，選中卡位於組內最前面。
   輪播不召回位置、不縮放，也不承諾所有摘要仍可見；重新 formation 才整理回來。
8. 新卡預設在自己的群組區域，既有卡片不因新增或同步自動重排。
9. Formation 可復原位置、尺寸與基本疊序；不回退內容或遠端修改。
10. 指定群組快捷鍵啟動拖拉模式，該組暫時浮到 IDE／瀏覽器等一般 App 上方；
    結束操作恢復原常駐層級。全群組入口按使用者授權採納，供不熟群組者使用。
11. 單擊選中、雙擊編輯；拖到群組接收標籤，或按 Shift 拖入區域，放開才轉組。
    卡片 action 的「移至群組」保留；轉組不等於 formation。
12. 預設唯讀且滑鼠穿透；本機操作鎖與來源權限、跨裝置寫入分開。
13. Windows、macOS、Linux 保留為必要桌面平台；自有 Apple／Google App 上架目標保留。
14. 1.0 不加入 Focus／番茄鐘／回顧，不複製參考應用的介面與架構。

後續同日明確答覆接受了「一般 App 上方」及第 11 點手勢；不得重新列為未回答問題。
初階使用者預設一組、全群組入口與 row-first 的具體安排來自使用者委託設計的範圍，
不宣稱是維護者逐字指定的按鍵／預設群組名稱。

## Consequences

### Positive

- 快速記錄與自由桌面擺放共存，整理意圖與改組意圖明確。
- 來源、共用歸屬、每機版面及短暫互動可分別演進。
- 單組與全組操作共用一套語意，新手無需先建立九組。

### Negative

- 必須管理暫時浮層、指標追蹤、草稿保存及復原，不能用一個 unlock 布林值處理全部。
- 有限桌面容量無法無條件保證任意多張紙的摘要可見，需預覽及明確容量界線。
- 跨平台原生 surface 不保證任意疊序，呈現實作須符合 [ADR-007](007-desktop-scene-and-platform-host.md) 的限制。

### Neutral

- 卡片 body 格式、附件、備份完整範圍、逐卡分層設定 UI 仍是 SPEC-003 的 Q。
- 「最多九組」不是永久限制未來 schema，也不要求九台機器。
- Google 來源與備份提案繼續存在，但舊版排除清單未獲自動批准。

## Alternatives Considered

| 方案 | 處置 |
|---|---|
| 每台機器一個包含很多獨立 issue 的 note 容器 | 被一事一卡的後續要求取代 |
| 單張展開高度／整組 accordion | 使用者明確拒絕，不作產品模式 |
| 區域當硬容器、跨區就改組 | 不符合自由拖曳要求 |
| 輪播搬位置、拖離後退出群組輪播 | 被暫時 z-order 與邏輯群組規則取代 |
| 新卡或同步後自動 formation | 違反顯式重排授權 |
| 全桌面解鎖是唯一入口 | 增加單群組操作；全群組仍保留便捷入口 |
| 立即導入完整 PM／Agent 工作流 | 保留研究，第一版不強制 |

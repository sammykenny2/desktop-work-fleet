# 發佈現況

更新：2026-10-03。沒有 build、安裝包、商店條目或部署服務。

目標為 iOS／macOS 的 Apple App Store 與 Android 的 Google Play。Windows 優先評估 Microsoft Store MSIX；Linux 考慮 GitHub Releases 搭配明確支援矩陣。

平台能力、套件可安裝與商店核准是不同驗證，必須分開記錄。細節與官方來源見 [發佈及授權研究](resreach/2026-10-03-store-distribution-and-license-analysis.md)。

本次沒有購買憑證、建立金鑰、開發者帳號、遠端 repo 或公開任何檔案。

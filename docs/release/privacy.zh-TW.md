# Work Fleet 隱私與資料說明

以下內容供產品維護者發布於 `WORK_FLEET_PRIVACY_URL`。發布時加入實際維護者名稱、聯絡方式及生效日期。

Work Fleet 用於記錄便箋、待辦、草稿與附件。使用者可以只用本機工作空間，或主動登入 Google 以同步資料。

## 本機資料

便箋內容、群組、草稿、附件、版本歷史、待送同步操作及本機版面保存於装置。
原生 App 使用作業系統安全儲存保護本機資料與憑證。解除安裝或清除 App 資料可能刪除這些內容；
作業系統帳號、裝置金鑰或安全儲存無法使用時，原本加密內容可能無法讀取。
請使用可攜備份保存重要內容，妥善保管備份密碼。

## Google 同步

登入與 Drive 授權由 Google／作業系統的原生流程處理。
App 使用 Google 帳號的穩定識別碼區分工作空間，並以 email 顯示正在使用的帳號。
登入資料不以便箋本文形式保存，也不納入便箋備份。

啟用同步後，便箋、群組、附件及版本資料會傳到該帳號的 Google Drive App 資料空間。
Google 接收 OAuth 與 Drive 請求所需的帳號／網路資訊；其資料處理適用 Google 的隱私政策。
Work Fleet 沒有自家便箋內容 server，不要求存取一般 Drive 資料夾。
登出會中止本機同步並移除 App 保存的登入資料，已保存的便箋仍留在原帳號分區。

## App 更新

使用者在設定或系統匣檢查更新時，App 會向 GitHub 查詢本產品公開的發布資訊並下載新版安裝檔。
GitHub 接收一般 HTTP 請求資訊（例如 IP 位址與 App 名稱和版本的 User-Agent），其資料處理適用 GitHub 的隱私政策。
檢查時不傳送便箋、帳號或裝置識別資料，也不會在使用者未操作時自動連線。

## 備份與版本保留

使用者自行選擇備份位置與是否以密碼加密。完整備份包含本文、附件、草稿與歷史，應視為私人檔案。
明文備份可由取得檔案的人讀取；密碼加密備份需要密碼才能開啟，維護者無法替使用者恢復密碼。
檔案提供者或使用者自行選擇的雲端位置可能接收備份檔案。
App 的完成、封存與刪除區操作保留必要的版本歷史，以支援同步與衝突處理。
刪除便箋不代表其所有歷史立即從本機、Drive 或既有備份移除。

## 權限與聯絡

App 只在使用者選擇附件或備份位置時請求該檔案／資料夾的存取。
沒有加入廣告 SDK、定位、聯絡人、麥克風或相機功能，也沒有自行加入追蹤分析 SDK。
Google／平台 SDK 的處理依各自條款；商店揭露需與實際散布套件的依賴及行為一致。

如需支援，請使用產品公開的支援網址或聯絡 email。維護者應只要求診斷所需資訊；
不要在支援訊息分享 OAuth token、簽章金鑰、密碼或不希望他人讀取的便箋／備份。
